# E3DEX 4.4.1 - Paddle 정기 구독 · 서버 실행 (Claude Code · Codex)

활성 Paddle 정기 구독 결제가 필요합니다. 관리자가 수동 이용 권한을 부여한 계정도 사용할 수 있습니다. 별도 가입 승인은 필요하지 않습니다. 배관·구조·장비·PLAN 생성은 관리 서버에서 실행되므로 기능 개선은 바로 적용됩니다. 이 PC에는 로그인과 E3D 연결·매크로 실행 부분만 설치됩니다.

## 처음 한 번

1. Claude Code 또는 Codex의 플러그인 마켓플레이스에서 E3DEX를 설치(또는 업데이트)합니다. 두 프로그램을 같은 PC에서 함께 써도 됩니다.
2. 관리자가 알려준 주소의 `/signup`에서 가입한 뒤 Paddle 정기 구독을 결제합니다. 수동 이용 권한을 받은 계정은 결제 없이 사용할 수 있습니다.
3. Claude Code 또는 Codex의 새 채팅에서 요청합니다.

> E3DEX 로그인해줘.

브라우저가 열리면 로그인하고, 채팅에 표시된 코드와 같은지 확인한 뒤 **연결하기**를 누릅니다. 계정이 없으면 같은 화면에서 신청할 수 있습니다. 미결제 상태라면 Paddle 결제 페이지로 안내됩니다. 결제 완료 후 PC 연결을 마치세요.

4. 처음 쓰는 PC라면 기존처럼 초기 설정을 요청합니다.

> E3DEX 초기 설정해줘. Design과 Draw 연결 모듈을 설치하고, 작업할 프로젝트 로그인 후 읽기 전용 실행까지 검증해줘. SAVEWORK는 하지 마.

## 알아둘 점

- 관리 서버에 인터넷으로 연결되어 있어야 사용할 수 있습니다. 매 작업마다 구독 또는 수동 이용 권한를 확인합니다.
- 생성 기능 업데이트는 자동입니다. 관리자가 새 버전을 올리면 다음 작업부터 적용됩니다. E3D 연결 부분이 바뀔 때만 마켓플레이스에서 플러그인을 업데이트합니다.
- 관리자가 사용을 중지하면 바로 사용할 수 없습니다.
- 비밀번호는 브라우저에만 입력합니다. 채팅에 입력하지 마세요.
- 구독 결제·해지·영수증: "E3DEX 구독 관리 열어줘" (`e3d_account(action="billing")`). Paddle 고객 포털에서 관리합니다.
- 로그아웃: "E3DEX 로그아웃해줘" (이 PC의 연결이 서버에서도 해제됩니다).
- Claude Code와 Codex는 같은 로그인 정보를 함께 씁니다. 한쪽에서 로그인하면 다른 쪽에서도 바로 사용할 수 있습니다.

## 오류별 조치

| 표시 | 의미 / 조치 |
|---|---|
| `LOGIN_REQUIRED` | 로그인이 필요합니다. "E3DEX 로그인해줘" |
| `PAYMENT_REQUIRED` | 활성 구독 결제가 필요합니다. 표시된 결제 주소를 열거나 "E3DEX 구독 관리 열어줘"를 요청하세요. 결제 후 원래 작업을 다시 요청합니다. |
| `ACCESS_REVOKED` | 관리자가 사용 권한을 해제했습니다. 관리자에게 문의하세요. |
| `SERVER_UNREACHABLE` | 관리 서버에 연결할 수 없습니다. 인터넷/프록시를 확인하세요. |
| `LOADER_OUTDATED` | 마켓플레이스에서 플러그인을 최신 버전으로 업데이트하세요. |
| `core_failed` | 서버에서 생성에 실패했습니다. 메시지를 관리자에게 알려주세요. |

## 저장 위치

- 데이터 폴더 이름은 이전과 같은 `%LOCALAPPDATA%\E3DBridge`를 그대로 씁니다 (기존 로그인·Python·작업 기록 유지).
- 로그인 정보: `%LOCALAPPDATA%\E3DBridge\loader` (Windows 계정 암호화)
- 서버가 만든 매크로와 실행 기록: `%LOCALAPPDATA%\E3DBridge` (3.4.0과 같은 위치)
- Python 런타임과 작업 기록 위치는 3.4.0과 같습니다 (`%LOCALAPPDATA%\E3DBridge`).

최초 실행에 Python 3.13.13 다운로드가 필요한 점, E3D 2.1 / Windows x64 전용인 점은 3.4.0과 같습니다. PLAN DXF 내보내기도 서버에서 처리하므로 PC에 별도 패키지를 받지 않습니다. 자세한 기능 설명은 로그인 후 `e3d_guide`가 최신 버전으로 제공합니다.
