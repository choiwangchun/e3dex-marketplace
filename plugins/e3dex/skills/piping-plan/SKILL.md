# PIPING PLAN

평면도의 각 간격 치수는 어느 두 배관을 재는지, 각 지시선은 어느 배관의 어느 표고를 읽는지 도면에서 추적할 수 있어야 한다. 도면 일부를 고치는 요청이면 해당 뷰의 기존 표현과 편집 가능한 객체를 살려 수정한다.

## 도면과 모델 준비

1. 지정된 프로젝트·MDB·DRAW 시트·뷰를 현재 세션에서 식별한다. 실모델 접근은 설치된 E3DEX의 세션 및 작업 대상 선택 절차를 따른다. 기존 시트면 뷰의 투영 방향, 축척, 표시 목록과 잘림 범위를 먼저 읽는다.
2. 표시할 PIPE·BRAN과 필요 구조물을 식별한다. 원본과 복사본을 함께 보여 줄 때에는 각 위치의 모델 객체와 좌표를 직접 읽는다. “차례대로” 지정된 이동량은 구간 거리와 원본 대비 누적으로 구분한다. 도면에 이미 있는 복사본을 추가로 생성하지 않는다.
3. 참조 PDF에서는 실제 용지 크기·방향, 본도와 주석 및 표제란의 배치를 읽는다. 참조 DWG에서는 모델/종이 공간, 단위, 뷰포트와 출력 축척, 문자 높이·회전, 치수 형태, 선종류·색·선가중치를 확인한다. 참조 도면의 축명·라인번호·표고·개정정보는 현재 프로젝트 데이터로 채운다. 용지와 축척은 출력 가능한 영역에 본도와 외곽 주석까지 들어가는 조합으로 정한다.

## 요청별 작업

| 작업 | 적용 방법 |
|---|---|
| 배관 및 랙 평면도 | 뷰의 배관·미니랙을 실제 모델에서 투영한다. 랙 축, DWG LIMIT, 방위, 키플랜, TOS는 요청 또는 참조 양식에 맞춰 배치한다. 기둥 중심과 보 상단의 근거가 되는 모델 부재를 확인한다. |
| 배관 사이 간격이 어색함 | [치수와 지시선](references/annotations.md)에 따라 측정 단면, 양 끝점, 실제 출력 위치를 각각 확인한다. 측정값이 맞고 표시만 잘못된 경우에는 치수열과 보조선만 고친다. |
| 라인번호와 BOP | 주석이 가리키는 직관에서 라인 식별자와 BOP를 구한다. 수평 지시선 위에 라인번호, 아래에 BOP를 놓는다. 상·하단 지시선은 같은 규칙을 90° 회전하여 읽게 한다. 자세한 기준은 [치수와 지시선](references/annotations.md)을 따른다. |
| DWG 및 출력 | [DWG·PDF 검수](references/export.md)에 따라 최종 DWG를 다시 열어 객체와 색을 확인하고, 해당 DWG의 페이지 설정으로 출력한 PDF를 확인한다. 파일 형식은 요청에 맞춘다. |

수정 후 시트를 갱신하고 모델 참조와 뷰 배치를 다시 읽는다. DWG 후처리로 만든 레이어·치수·페이지 설정은 DRAW 시트에 반영된 항목과 구분해 보고한다. 납품 파일 위치와 DRAW의 실제 저장 상태를 적는다.
