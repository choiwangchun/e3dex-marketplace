# DWG와 출력 검수

## DRAW 시트에서 최종 파일까지

1. 갱신된 시트에서 모델 형상, 축척, 주석 방향과 치수점을 읽는다. 작업 대상 시트를 DWG로 내보낸다. 기존 DWG만 수정해 달라는 요청이면 파일 복사본에서 시작한다.
2. 최종 DWG를 다시 열고 대표 배관 외곽선·중앙선·랙의 유효 색상을 확인한다. ACI 빨강 1·초록 3이 요구되면 색인 번호와 True Color 덮어쓰기를 검사한다. ByLayer·ByBlock 객체는 소속 레이어와 블록 참조까지 따라간다. 검은 출력이 생기면 모델 객체 색, DWG 매핑, CTB/STB 인쇄 설정을 각각 점검한다.
3. 치수의 편집성이 요구되면 객체 형식이 DIMENSION인지, 지시선은 의도한 꼭짓점과 방향을 유지하는지 확인한다. 내보내기에서 선과 문자로 분해됐다면 겹쳐 그리지 말고 해당 치수만 모델 기준점에서 재구성한다. CAD의 편집 가능 여부와 E3D 모델에 대한 연동 여부는 따로 확인한다.
4. 지정된 용지·출력 범위·방향·축척으로 PDF를 만든다. 축척을 지정한 경우 자동 맞춤에 의한 재축소를 확인한다. 예를 들어 1:150이면 모델의 15,000 mm가 지면에서 100 mm다. 흑백 출력 요청은 페이지의 플롯 스타일에 적용한다. 축척 막대나 알고 있는 축간 거리를 출력물에서 다시 잰다.
5. PDF를 전체 페이지로 렌더링해 범위·잘림을 확인하고, 가장 촘촘한 배관 묶음을 확대한다. 중심에서 치수의 양 끝까지 눈으로 따라가며 라인번호와 BOP의 좌우/상하 관계를 읽는다. 점검한 DWG와 PDF를 함께 넘긴다.

## 치수 끝점 대조 도구

`scripts/check_dimensions.py`는 Python 표준 라이브러리만 사용한다. **최종 DWG를 다시 연 뒤 내보낸 ASCII DXF**와 모델에서 독립적으로 준비한 기대값을 입력한다. 직접 배치된 모델 공간의 XY축 선형 DIMENSION에 대해 두 정의점·축·치수선 위치·측정값을 일대일로 비교한다. 블록 내부나 종이 공간에 놓인 치수, 사선 치수, 분해된 객체는 해당 CAD의 객체 조회 기능으로 검사한다.

기대값 JSON에서 `points`는 시트 뷰로 투영한 후 **DXF 모델 공간 단위**로 환산한 좌표다. `baseline`은 X방향 치수면 치수선의 Y좌표, Y방향 치수면 X좌표다. 한 그룹 안의 연속한 두 점이 치수 하나에 해당한다. 예를 들어 다음 두 치수는 각각 300 및 650 도면 단위다.

```json
{"groups":[{"name":"north","axis":"x","points":[[1000,2000],[1300,2000],[1950,2000]],"baseline":2450}]}
```

```sh
python scripts/check_dimensions.py final.dxf expected.json --tolerance 0.02
```

허용오차는 DXF 좌표 단위에 맞춘다. 지정한 구간 중 누락·중복·불일치가 있으면 종료 코드가 0이 아니다. 성공은 입력한 구간에 대한 검증이다. 전체 치수 수, 연동 여부, 실제 표시 단위·반올림·화살촉·겹침은 DWG와 출력물에서도 확인한다.
