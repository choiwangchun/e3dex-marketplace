# 배관 간격과 지시선

## 어느 두 배관 사이인가

- 치수의 의미를 정한다. 평행한 배관의 배치 치수는 일반적으로 중심 간격(C/L–C/L)이다. 사용자가 외면 간격이나 보온 후 순이격을 요청하면 해당 단면에서 외경과 보온 두께를 반영하고 기준을 도면에 명시한다. 평면 투영 간격과 서로 다른 표고에서의 3차원 최소거리는 별도 측정값이다.
- 같은 횡단 위치에서 배관 축과 만나는 점을 구한다. 그 점들을 시트 좌표로 투영해 측정축 방향으로 정렬하고 이웃한 두 점씩 체인 치수를 만든다. 뷰가 회전했으면 뷰의 두 축을 사용한다. 평행한 사선 배관의 직각 간격은 배관 축에 수직인 방향으로 잰다.
- 각 구간에 두 모델 참조, 측정 위치, 투영 좌표와 기대값을 기록한다. 북측·남측의 엘보와 오프셋 때문에 한쪽의 인접 순서나 간격이 달라질 수 있다. 각 측정열과 복사 위치를 따로 조회한다. 분기 묶음 사이의 피치는 네 묶음이면 동일한 역할의 점 네 개를 택해 세 구간으로 표시한다.
- 가능하면 DRAW의 치수점에 실제 모델 지점이나 P-point를 연결한다. 적합한 연결점이 없으면 모델에서 읽은 좌표와 기준을 남긴다. 표시 문자를 덮어써서 실측값을 맞추면 후속 수정에서 오류가 숨는다.

## 배관 끝에서 읽는 순서

**배관 중심 → 짧은 치수보조선 → 간격 치수열 → 라인번호와 BOP** 순으로 놓는다. 기준점은 배관에 고정하고, 지면에서 보조선 시작 여백과 치수선 위치를 조절한다. 배관 끝과 치수선 사이에 세로 라인번호가 끼면 값이 맞아도 어느 관을 재는지 읽기 어렵다.

촘촘한 배관에서는 각 보조선을 배관 중심에서 짧게 곧장 뽑는다. 지시선도 같은 축을 따라 나와야 한다면 치수열을 지난 뒤에 꺾고, 문자와 만나는 끝부분을 세로로 정렬한다. 중복 선분·겹친 화살촉·문자 관통은 확대 출력으로 확인한다. 가장 좁은 간격에서 문자와 화살촉이 맞물리면 행을 나누거나 상세 뷰를 사용한다. 랙 축간·전체 길이·복사 피치는 배관 간격과 다른 열에 둔다.

## 라인번호, BOP, TOS

- 라인번호는 해당 프로젝트의 PIPE 이름·속성 또는 지정된 조합 규칙으로 만든다. 접속부 크기가 바뀌는 경우 지시 대상 구간의 구경을 확인한다.
- BOP는 지정한 기준면에서 배관 외면 최하단까지의 표고다. 수평 원형 직관에서는 축 표고에서 **실제 외경의 절반**을 뺀다. 호칭경을 외경으로 대입하면 오차가 생긴다. 구배·편심 리듀서·수직 단차가 있으면 지시점의 단면과 표고를 확인한다. 보온 외면이 기준이면 그 기준을 표시한다.
- 수평 지시선은 라인번호가 위, `BOP EL. <값>`이 아래에 오도록 한다. 상·하단 세로 표기는 아래에서 위로 읽도록 90° 회전하면 라인번호가 왼쪽, BOP가 오른쪽에 온다. 동일 라인의 여러 구간이 다른 표고면 각 표기가 가리키는 구간을 분명히 한다.
- TOS는 해당 구조 부재의 실제 상단에서 읽는다. 경사 보 또는 서로 다른 상단 표고가 있으면 측정 지점별로 표시한다. BOP와 TOS의 기준면 및 단위를 통일한다.
