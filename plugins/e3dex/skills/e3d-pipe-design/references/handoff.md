# 장비팀 노즐 변경 인폼과 재검사

## 변경 인폼에 담을 내용

장비팀이 도면 한 장으로 **어느 노즐을 어느 기준에서 얼마나 옮기며, 무엇을 회신해야 하는지** 알 수 있게 작성한다. 장비팀 인폼 요청에는 검토용 문서나 도면을 만들고, 발송 요청은 별도로 취급한다.

| 항목 | 작성 기준 |
|---|---|
| 식별·목적 | 프로젝트·장비·노즐·연결 라인·리비전과 변경 사유. 간섭한 부재와 위치를 명시한다. |
| 변경 전후 | 같은 좌표계·단위의 노즐 접속면 중심, 방향, 돌출량, 구경·플랜지 등급·면 형상을 전/후로 나란히 적는다. 높이 변화에는 부호를 넣는다. 장비 기준면이 있으면 WORLD 좌표와 함께 표시한다. |
| 영향 범위 | 조정한 엘보·직관·리듀서·분기·서포트, 바뀐 스풀의 면간과 인출 방향. 상대 장비·발판과의 관계는 치수 있는 평면 또는 입면으로 표현한다. |
| 검증과 회신 | 재접속 결과와 검사한 정비 공간, 확인이 남은 장애물·현장 치수·허용하중. 노즐 보강·제작 가능 위치 등 장비팀 결정을 구체적으로 적는다. |
| 발행 상태 | 모델 측정값·도면값·가정값의 출처, 모델 저장 여부와 문서의 용도. 이전 리비전 발행 후 달라진 발판과 검사 결과는 새 상태로 구분한다. |

## 변경 후 다시 봐야 하는 범위

| 발생한 변경 | 재확인할 항목 |
|---|---|
| 노즐 이설 또는 규격 변경 | 장비 몸체·주변 부재 간섭, 양 끝 포트와 상대 플랜지, 인접 직관 길이, 새 저점, 볼트 인출, 변경 인폼 |
| 밸브 또는 스풀 이동 | 발판에서 조작과 분해, 양끝 볼트, 분해 후 개구와 잔류 배관 지지, 반출과 하역 |
| 서포트·철골·발판 변경 | 실제 지지 접촉과 고정측, 이동 경로, 계단 첫 단과 하단 회전부, 볼트·공구 여유 |
| 중단 뒤 재개 | 현 세션에서 라인·노즐·발판·임시 그룹의 존재와 리비전 확인. 부분 생성된 요소를 식별하고 남은 변경만 수행 |

짧은 답변이면 **적용 위치와 변경 → 검사 범위와 결과 → 보류 사유와 저장 상태** 순서로 쓴다. 예를 들어 스풀만 통과한 경우에는 “지정한 하역 위치까지 고정 철골과의 간섭은 미검출. 계단 첫 단 위 보 돌출은 미해결”처럼 두 결과를 한눈에 볼 수 있게 한다.
