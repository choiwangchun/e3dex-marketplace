# 노즐 접속과 배관 루팅

## 접속면에서 시작하기

| 확인 대상 | 읽을 값 | 설계에 쓰는 방법 |
|---|---|---|
| From / To 노즐 | 태그, 소유 장비, 접속 포트의 WORLD 좌표와 외향 방향, 구경, 규격·등급·면 | 노즐 원점과 실제 플랜지 면이 다른지 확인한다. 동일 좌표계에서 상대 플랜지와 방향을 맞춘다. |
| 배관 설계 기준 | P&ID·라인 리스트의 적용 리비전, 유체, 라인 클래스와 구경, 요구된 경사·배액 조건 | 자료와 모델이 다르면 차이 및 영향을 지정한다. 특정 라인의 운전 조건을 인접 라인에서 추정해 확정하지 않는다. |
| 프로젝트 스펙 | 해당 구경의 관·엘보·밸브·TEE/분기관·상대 플랜지·가스켓·리듀서·드레인 끝단 품목 | 스펙 이름이 조회되더라도 필요한 구경·접속 조합이 실제로 존재하는지 확인한다. |
| 경유 구간 | 기존 발판 상면과 하부 보, 주위 장비, 배관, 서포트 설치 가능 철골 | 중심선 외에 플랜지 외경, 보온 두께가 적용되는 구간, 밸브 조작부와 지지면을 반영한다. |

**구경 변경과 플랜지 규격 변경을 구별한다.** 리듀서는 서로 다른 구경을 연결한다. JIS 10K와 ANSI Class 150처럼 상대 플랜지 규격이 다르면 리듀서를 넣어도 볼팅 조합은 해결되지 않는다. 해당 규격의 승인된 전환 조립체가 있는지 찾는다. 임시 장비 노즐의 규격 변경이 대안이면 변경 대상과 상대 부품을 제시하고, 이미 승인된 선택을 적용한다. “대충 하나”라는 요청만으로 기존 장비 인터페이스를 바꾸지 않는다.

## 조립과 확인

1. 기존 PIPE/BRAN이 있으면 양 끝 노즐 연결 대상, 부품 순서와 분기 위치를 먼저 읽는다. 노즐 면부터 가스켓·상대 플랜지·리듀서의 면간과 방향을 반영해 중심선을 잡는다. 편심 여부·밸브 형식은 서비스와 적용 자료에서 정한다.
2. 밸브의 유동 방향이 지정된 경우 설치 방향을 맞추고, 핸들 또는 액추에이터의 전체 조작 범위를 확인한다. 분해 요청이 있으면 탈착면, 고정측, 스풀 면간을 이때 결정한다.
3. 수평처럼 보이는 구간도 실제 고도·경사·리듀서 형상으로 저점을 찾는다. 복수의 포켓이 있으면 각 포켓에서 지정 드레인으로 배액이 가능한지 확인한다. 드레인 분기 방향, 밸브 사양 및 끝단 접속 형식을 해당 스펙과 요구조건에 맞춘다. 플러그 마감 요청이면 플러그와 맞물리는 암나사 등 대응 단부, 공구 접근, 분해 여유까지 본다.
4. 수정 뒤 양 끝 노즐–분기 HEAD/TAIL 연결 참조, 포트 위치·맞물림 방향·구경·끝단, 직관 유효 길이, 밸브와 드레인 분기 연결을 다시 읽는다. 서로 가까이 보이는 미연결 포트, 뒤집힌 리듀서, 누락된 가스켓, 의도하지 않은 열린 끝이 있는지 확인한다.

결과에는 양 끝 태그와 접속 조건, 적용 스펙, 실제 저점과 끝단, 아직 결정되지 않은 품목을 남긴다. 노즐을 옮겼으면 그 면을 기준으로 인접 직관·엘보·리듀서·분기의 연결성과 종전 저점이 유지되는지도 다시 확인한다.
