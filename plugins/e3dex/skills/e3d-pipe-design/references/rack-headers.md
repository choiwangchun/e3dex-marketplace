# 일반 배관 루팅 원칙

## 설계 입력과 배치 순서

승인된 P&ID에서 유동 방향, 분기, 밸브의 종류와 배열, 계측 위치, 끝단 조건을 읽는다. 라인 리스트와 배관 클래스에서 운전·설계 조건, 구경, 재질, 보온·트레이싱 범위를 확인한다. 장비 도면의 노즐 위치·방향·접속 규격을 모델과 대조하고, 미확정 접속점은 인계 항목으로 남긴다.

평면에 접속점, 구조물 통과 위치, 장비 반출 경로를 표시한다. 단면에는 보 높이, 통행 공간, 타 공종 및 증설 공간을 표시한다. 자연유하관, 펌프 흡입관, 대구경관, 열변위가 큰 관 등 **경로 선택이 제한되는 라인**부터 자리를 잡는다. 우선순위는 확보해야 할 낙차, 장비 조건, 하중과 가용 공간을 보고 정한다.

## 경로를 결정할 때

| 판단 항목 | 모델에서 확인할 내용 |
|---|---|
| 직선과 굴곡 | 랙·건물의 주축을 따라 같은 방향의 배관을 평행하게 놓는다. 국부 간섭이 생기면 라인 순서와 분기 위치를 조정해 엘보 수를 줄일 수 있는지 검토한다. 구배 유지, 열변위 흡수 또는 구조물 통과에 필요한 굴곡은 확보한다. |
| 랙 단면과 간격 | 사용할 단과 타 공종 공간은 프로젝트 배치 기준에 따라 정한다. 중량관은 기둥 근처에서 하중을 전달할 수 있는지 보 반력 및 분기 동선과 함께 검토한다. 인접 배관과 철골 사이의 여유는 보온 외면, 플랜지, 슈, 밸브 돌출부와 운전 중 이동 범위로 확인한다. 요구 이격에는 측정할 두 기준면을 표시한다. |
| 구배·벤트·드레인 | 자연유하관은 출구까지 관내 바닥 높이를 따라가며 구배의 연속성과 가용 낙차를 확인한다. 액체 배관의 고점에는 기체가, 가스·증기 배관의 저점에는 액체가 모일 수 있다. 불필요한 포켓은 루트에서 없애고, 남은 고점·저점은 운전·정지·시험 조건에 맞게 벤트·배수할 수 있는지 확인한다. |
| 지지와 열변위 | 보, 기둥, 프레임에 실제로 받침을 설치할 위치를 경로와 함께 잡는다. 밸브·라이저의 집중하중과 운전·시험 시 배관 중량이 어디로 전달되는지 본다. 온도 변화가 큰 구간은 이동 방향, 자연 굴곡, 앵커·가이드 위치를 함께 검토하고 노즐에 전달되는 힘과 모멘트를 장비 허용값과 대조한다. |
| 장비·계측기 성능 | 펌프 흡입부는 공기 포켓과 압력손실을 줄이고 제조사의 흡입 조건을 따른다. 계측기·제어밸브는 해당 기기 사양에서 요구하는 설치 자세, 유동 방향, 전후 직관부를 먼저 확보한 뒤 인접 엘보와 분기 위치를 정한다. |
| 조작·정비 접근 | 작업자가 설 위치에서 핸드휠의 전체 조작 범위를 확인한다. 볼트, 스트레이너 망, 액추에이터, 스풀을 실제 탈착 방향으로 움직여 보고 통로·피난로·사다리 접근 및 장비 반출 공간이 확보되는지 확인한다. |
| 제작·시공 | 스풀의 반입·양중, 현장 용접·볼팅, 검사 순서를 따라 접근 공간을 점검한다. 탈착 스풀을 빼낸 뒤에도 잔류 배관과 장비측 배관을 지지할 수 있는지 본다. |

## 모델과 ISO 검증

변경한 경로의 접속면, 구배, 받침 위치와 간섭을 먼저 재검사한다. ISO 출력이 범위에 포함되면 분기 방향, 끝단, 치수를 도면과 대조한다. 다음은 E3D에서 개별 오류를 추적하는 방법이다.

| 관찰한 현상 | 확인과 조치 | 완료 근거 |
|---|---|---|
| CHECK에서 접속·단부 경고가 나온다 | 라인·브랜치·HEAD/TAIL별로 상대 참조, 포트 좌표·방향, 접속 유형을 읽는다. 모델 오류를 수정하고 승인된 미접속, 카탈로그 오류, 사용자 정의 심벌은 각각 사유와 후속 조치를 남긴다. | 동일 범위 재검사에서 해결·잔여 건수와 근거를 보고한다. 사용자 정의 심벌은 실제 ISO에서도 확인한다. |
| ISO에 DOUBLEBACK이 나온다 | 마지막 부품의 실제 출구면과 브랜치 끝점 사이에서 진행 방향이 뒤집히는지 확인한다. 원인이 끝점이면 그 면에 위치와 방향을 맞추고 양쪽 접속을 다시 읽는다. | 수정한 라인의 ISO를 새로 출력하고 해당 도면의 생성 결과와 로그에서 경고 소멸을 확인한다. |
| ET가 예상과 다른 구간에 보인다 | 도면의 분기·치수로 해당 BRAN을 찾고, 라인 리스트의 트레이싱 범위와 PIPE·BRAN·구성품의 `TSPEC`을 대조한다. 보온은 `ISPEC`으로 따로 확인한다. 부분 트레이싱은 시작·종료 경계 양쪽을 확인하고, 수정한 부품은 `TSPEC`을 재조회한다. 표제란이 쓰는 속성(예: `:TRACE`)과 모델의 트레이싱 사양을 각각 확인한다. | E3D 2.1 ISODRAFT의 `TracingControl ON`은 튜브에 표시하며 `ALL`은 구성품까지 표시한다. 해당 ISO에 필요한 옵션을 적용해 다시 출력하고 도면의 표제·표시 범위와 로그를 확인한다. [AVEVA 명령 설명](https://help.aveva.com/AVEVA_Everything3D/2.1/ISORM/ISORM3.03.114.html) |

결과에는 실제로 확인한 라인과 브랜치, 미접속 경계, 임시 구경, 보류한 지지대, ISO 출력 결과와 모델 저장 여부를 적는다. 라우팅 수정 후에는 영향받은 연결과 인접 라인의 간섭을 다시 확인한다.
