# 랙 유틸리티 헤더 설계

## 1. 경계와 흐름부터 정한다

- 라인별로 서비스, 설계 구경, 공급·회수 방향, 시작 TP, 수신 노즐, 분기 수와 끝단 마감을 한 줄에 적는다. 리시버를 거치면 입구 공급관과 출구 분배 헤더를 각각 추적한다. 마크업의 화살표를 모델의 장비·노즐과 대조한다.
- 기존 소구경 라인이 참고용이면 접속 위치와 밸브 배열을 읽고, 요청 구경의 신규 헤더를 만든다. 참조번호가 BOX이면 위치만 특정할 수 있다. 실제 노즐이 없고 미접속 유지가 합의됐으면 경계면의 좌표·방향과 미접속 사유를 기록한다.
- 프로젝트 스펙에서 관, 엘보, 티, 플랜지, 가스켓, 밸브를 **구경과 접속 조건별로** 확인한다. 가스켓 하나가 없으면 그 품목을 명시한다. 가령 26″ 설계에 24″ 임시 모델을 승인받았다면 설계 구경과 모델 구경을 함께 기록하고, 증경 후 플랜지 외경·엘보 반경·랙 여유·지지 하중·노즐 접속을 다시 검토한다.

## 2. 랙 단면을 먼저 배치한다

| 배치 결정 | 확인할 내용 |
|---|---|
| 사용할 단과 빈자리 | 랙 단면에 기존·예정 라인, 보 상단, 케이블트레이·덕트 및 증설 공간을 표시한다. 최상단이 타 공종용이면 가용 단에서 배치한다. |
| 라인 순서와 간격 | 대구경·중량관은 기둥에 가까운 외측을 우선 검토하고 보 반력, 지지점, 분기 접근성을 확인한다. 공급·회수 등 같은 방향의 관은 평행하게 배치한다. 간격은 보온 후 외경과 플랜지·슈·밸브의 최대 돌출부로 확인한다. |
| 받침 높이 | 랙 보 상단을 기준으로 관 하단(BOP), 보온 외면 하단, 슈 높이를 구분한다. “랙에서 100 mm”라는 조건은 적용 라인과 측정 기준면을 명시한 뒤 단면에서 검증한다. 받침 상세가 후속이면 필요한 높이와 위치를 남긴다. |
| 직선과 분기 | 랙 진행 방향으로 중심선을 유지하고 필요한 위치에서 티로 분기한다. 작은 간섭은 인접 라인의 배치 조정 가능성부터 본다. 오프셋이 필요하면 피할 대상과 복귀 위치를 정한다. 사용자가 제외한 부재는 해당 검토에서만 제외한다. |

## 3. 밸브를 조작하고 실제로 분해할 수 있게 배치한다

- TP에서 유동 방향으로 승인된 배열을 읽는다. 예를 들어 스팀 인입이 **게이트 → 스펙타클 블라인드 → 게이트 → 체크**, 응축수가 **게이트 → 스펙타클 블라인드 → 게이트**이면 각각의 배열을 적용한다. 가스켓·플랜지로 시작하는 장비 접속은 별도 조건이다. 체크밸브의 허용 설치 방향과 유동 방향을 대조한다.
- 병렬 인입부는 TP 접속면을 기준으로 정렬한다. 핸드휠이 겹치면 축을 직선으로 둔 채 인접 열 간격, 교대 돌출 길이, 제조사가 허용하는 밸브 회전각을 검토한다. ±45° 교대 배치는 현장 조건에 맞는 한 가지 선택이다. 양쪽 핸드휠을 조작하고 스펙타클을 돌리고 볼트를 뺄 공간까지 확인한다.
- 예비 분기의 마감이 **플랜지 → 가스켓 → 블라인드 플랜지**이면 세 품목을 모두 모델에서 확인한다. 가스켓 접합면, 블라인드 배면, BRAN 끝점의 위치·방향·접속 유형을 차례로 읽는다.
- 펌프 흡입부는 제조사가 정한 직관 길이와 리듀서 배치를 따르고, 흡입 손실과 공기 포켓을 줄인다. 계측기·제어밸브는 사양서의 전후 직관 길이, 조작 위치, 계기 및 액추에이터 인출 공간을 확보한다.

## 4. 지지할 수 있는 경로를 잡는다

고온관은 운전 온도에서의 이동 방향, 앵커·가이드 위치, 분기와 노즐에 전달되는 변위를 함께 검토한다. 스팀과 응축수의 구배·저점은 실제 유동 방향과 프로젝트 배수 조건으로 정한다. 옥상 구간은 지붕 보를 따라 지지 가능한 높이로 보내고, 통행·간섭과 노즐 접근 방향이 허용하면 장비 직전에서 상승시킨다. 라이저 가이드, 옥상 받침, 노즐 전단 지지를 나중에 모델링할 경우 인계 항목으로 남긴다. 지지 반력과 노즐 허용 하중은 구조·응력 및 장비 자료로 검증한다.

## 5. 모델과 ISO를 차례로 확인한다

| 관찰한 현상 | 확인과 조치 | 완료 근거 |
|---|---|---|
| CHECK에서 접속·단부 경고가 나온다 | 라인·브랜치·HEAD/TAIL별로 상대 참조, 포트 좌표·방향, 접속 유형을 읽는다. 모델 오류를 수정하고 승인된 미접속, 카탈로그 오류, 사용자 정의 심벌은 각각 사유와 후속 조치를 남긴다. | 동일 범위 재검사에서 해결·잔여 건수와 근거를 보고한다. 사용자 정의 심벌은 실제 ISO에서도 확인한다. |
| ISO에 DOUBLEBACK이 나온다 | 마지막 부품의 실제 출구면과 브랜치 끝점 사이에서 진행 방향이 뒤집히는지 확인한다. 원인이 끝점이면 그 면에 위치와 방향을 맞추고 양쪽 접속을 다시 읽는다. | 수정한 라인의 ISO를 새로 출력하고 해당 도면의 생성 결과와 로그에서 경고 소멸을 확인한다. |
| ET가 일부 구간에만 보인다 | 프로젝트 트레이싱 스펙을 정하고 PIPE, 각 BRAN, 각 구성품의 TSPEC을 조회한다. 엘보·티·밸브 등 적용 대상의 빈 값이나 다른 스펙을 확인하고 수정 후 전수 재조회한다. 표제란이 쓰는 속성(예: `:TRACE`)과 모델의 트레이싱 사양을 각각 확인한다. | E3D 2.1 ISODRAFT의 `TracingControl ON`은 튜브에 표시하며 `ALL`은 구성품까지 표시한다. 해당 ISO에 필요한 옵션을 적용해 다시 출력하고 도면의 표제·표시 범위와 로그를 확인한다. [AVEVA 명령 설명](https://help.aveva.com/AVEVA_Everything3D/2.1/ISORM/ISORM3.03.114.html) |

결과에는 실제로 확인한 라인과 브랜치, 미접속 경계, 임시 구경, 보류한 지지대, ISO 출력 결과와 모델 저장 여부를 적는다. 라우팅 수정 후에는 영향받은 연결과 인접 라인의 간섭을 다시 확인한다.
