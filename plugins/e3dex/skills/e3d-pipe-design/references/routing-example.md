# 가상 예제 · 탱크 출구에서 필터 입구까지

가정한 작업은 탱크 출구와 필터 입구를 연결하고, 운전자가 기존 발판에서 차단밸브를 조작하고 필터 앞 스풀을 꺼낼 수 있게 하는 것이다. 다음은 설계 판단을 연습하기 위한 예시다. 실제 모델의 검사 기록이나 프로젝트 표준 치수로 사용하지 않는다.

| 주어진 조건 | 설계할 때 내릴 판단 | 확인할 결과 |
|---|---|---|
| 양쪽 접속 구경이 다르고 필터 도면의 플랜지 규격도 다르다. | 구경 차이는 리듀서로 처리할 수 있다. 플랜지 규격은 배관 클래스와 장비 도면을 대조해 승인된 전환 방법을 정한다. | 양 끝 규격과 상대 플랜지·가스켓 조합, 변경 승인이 필요한 장비 인터페이스 |
| 주관이 보 하부를 지났다 다시 올라가고 저점 드레인에 플러그가 필요하다. | 하부 관내면을 따라 유체가 모이는 구간을 찾고, 분기·드레인 끝단과 플러그가 맞물리는지 본다. | 저점부터 끝단까지 배액 경로, 플러그에 공구를 걸 수 있는 위치 |
| 운영자는 기존 발판에서 밸브를 조작하고 필터측 스풀을 옆으로 반출한다. | 난간 안쪽에서 손이 닿는 위치를 정한다. 양쪽 볼트를 빼낼 공간, 스풀을 내리고 돌리는 동작, 하역 위치를 따로 확인한다. | 핸들의 전체 조작 범위, 볼트 인출 방향, 스풀 회전 중 외곽 궤적과 고정 철골 사이의 여유 |
| 탈착부 바로 옆에 받침이 하나 있다. | 스풀을 분리한 상태에서 필터와 고정측 배관 중 무엇이 그 받침에 남는지 확인한다. 필요하면 고정측 지지점을 옮기고 인출 경로를 다시 검사한다. | 잔류 배관의 지지점, 실제 받침 접촉, 스풀과 서포트의 간섭 |
| 스풀 이동 형상은 통과했지만 계단 하부에서 작업자가 몸을 돌릴 공간이 부족하다. | 스풀 인출과 작업자 접근에 서로 다른 판정을 내린다. 계단·난간 변경이 범위에 있으면 수정 후 재검사한다. | “스풀 경로 통과, 작업자 접근 미해결”로 기록하고 장애 위치와 확인이 필요한 치수를 남긴다. |
