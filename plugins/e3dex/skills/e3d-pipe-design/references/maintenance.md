# 발판에서 조작하고 스풀을 빼는 배치

## 정비 동작을 그리는 순서

1. **작업자가 서는 곳을 찾는다.** 발판의 상면과 가장자리, 난간·발끝막이판·계단 출입구, 하부 보의 밑면을 읽는다. 바닥판 모델 원점과 실제 보행면이 다를 수 있다. 밸브 중심 높이, 핸들까지의 수평거리, 몸을 둘 자리, 손·공구가 난간을 지나는지를 확인한다.
2. **탈착할 부품과 남을 배관을 표시한다.** 밸브와 스풀 각각의 두 분리면, 가스켓, 고정측 플랜지, 분해 순서를 정한다. 스풀을 빼야 밸브가 축 방향으로 빠지는 배치라면 두 동작을 순서대로 검사한다.
3. **플랜지 양쪽의 볼트와 공구 공간을 잡는다.** 볼트 원주 위치에 실제 스터드의 인출 길이와 소켓·렌치의 점유 공간을 반영한다. 원통 또는 환형 검사 형상을 사용할 때 반경·축방향 길이·기준면을 기록한다. 발주품 치수가 없으면 검사 가정과 미확인 공구 동작을 밝힌다.
4. **스풀의 연속 이동 범위를 검사한다.** 시작·끝 위치 사이에 통과하는 모든 공간을 포함한다. 플랜지 최대 외경과 돌출부를 포함한 스풀 전체를 대상으로, 하강·횡이동·회전·착지 구간을 실제 순서대로 나눈다. 회전하는 스풀은 회전 중 모서리 궤적까지 포함한다. 작업 발판 위 인계점까지만 검사했다면 그 지점까지를 확인 범위로 적는다.
5. **지지 조건을 확인한다.** 설치 상태와 스풀·밸브를 분리한 상태를 각각 본다. 남는 양쪽 배관의 받침 위치, 하중이 전달되는 보·기둥·기초, 가이드의 이동 방향, 슈·클램프와 인출 경로의 간섭을 확인한다. 노즐에 무게가 남거나 서포트가 탈착 스풀에만 붙는 배치는 수정한다. 중량, 반력, 열변위, 노즐 허용하중, 철골 접합·양중점 정격은 확보한 계산서나 프로젝트 자료 범위에서 판정한다.
6. **작업자가 실제로 도달할 수 있는지 잇는다.** 기존 발판에서 계단·중간참·작업 위치·반출 지점까지 연속으로 따라간다. 계단 폭은 난간 사이 유효폭, 단높이와 디딤 깊이는 완성면, 머리 여유는 보·배관 최하단을 기준으로 확인한다. 특히 첫 단 위로 돌출된 보와 마지막 단에서 방향을 트는 작업자의 공간을 검사한다. 새 계단·하부 발판이 요청 범위에 들어오면 기존 난간 개구부와 양쪽 보호 난간, 접속 보까지 모델에 반영한다.

## 간섭을 판정하는 방법

| 검사 결과 | 남길 증거 | 판단 |
|---|---|---|
| 배관과 지지대가 닿음 | 상대 부재와 면, 겹침 깊이, 의도한 지지 위치 | 받침면 접촉과 강재가 관을 관통하는 경우를 구분한다. |
| 이동 형상이 부품에 겹침 | 어느 동작의 어느 구간인지, 상대 부품이 그때 고정·이동·철거 중 어느 상태인지 | 시작 시 맞닿는 가스켓·탈착품은 개별 확인한다. 고정물과 겹치면 배치를 수정한 뒤 같은 경로를 다시 검사한다. |
| 진단 검사만 실행됨 | 검사 모드, 실제로 포함한 배관·장비·철골·발판, 검출 결과 | “검사한 범위에서 고정물 간섭 미검출”로 기록한다. 정식 검사를 수행하지 못한 이유를 함께 적는다. |
| 검사 실행 실패 또는 주변 모델 누락 | 오류와 빠진 구역, 마지막으로 확인한 리비전 | 판정을 미확인으로 둔다. 실행 결과가 없는 검사를 간섭 0건으로 집계하지 않는다. |
| 스풀은 통과하고 사람이 막힘 | 스풀 결과와 별도로 디딤판·난간·회전부 등 장애 위치, 치수 | 해당 정비 동선은 미해결로 남긴다. 스풀 통과만으로 비계 없는 작업이 가능하다고 판정하지 않는다. |

임시 게이지가 필요하면 영구 발판·배관과 구별되는 소유 그룹에 두고 이름·식별자·용도를 기록한다. 검사 후 임시 형상을 정리하되 보존 요청이 있으면 유지한다. 정리 전에 현재 그룹과 구성원을 대조하고, 삭제 뒤 임시 형상의 부재와 영구 모델의 존재를 다시 읽는다. 기록과 다른 구성원이 있으면 해당 그룹의 일괄 삭제를 멈춘다.
