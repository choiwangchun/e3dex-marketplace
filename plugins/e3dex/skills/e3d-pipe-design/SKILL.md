# E3D 배관 설계와 정비성 검토

기존 장비 노즐 간 배관을 설계할 때 **어느 면에 접속하는지, 어디에 서서 조작하는지, 무엇을 어느 방향으로 빼는지, 분해 후 남은 배관을 무엇이 받치는지**를 모델에서 확인한다. 신규 배관과 재루팅에는 [일반 배관 루팅 원칙](references/rack-headers.md)을 적용한다. 밸브 배열은 승인된 P&ID에서 읽고, 이격·구배·직관부는 프로젝트 기준과 해당 장비 사양에서 확인한다.

트레이싱 지정이 없는 신규 배관과 비트레이싱 구간은 `TSPEC=Unset`을 기본으로 한다. 티 등 부품을 생성·복사·교체하면 대상 PIPE·BRAN과 변경 부품의 `TSPEC`을 다시 읽고, 원본에서 따라온 트레이싱 값은 비트레이싱 구간의 해당 부품에서 해제한다. 라인 리스트 또는 프로젝트 사양에 전체·부분 트레이싱이 지정되어 있으면 지정 구간과 경계를 따른다. 기존 구간의 지정 근거가 불명확하면 기존 값을 보존하고 차이를 보고한다.

배관을 모델링할 때 `SHOP` 속성을 설정할 수 있는 모든 BRAN 구성품의 기본값은 `SHOP TRUE`다. 엘보·티·리듀서·밸브·플랜지·가스켓·블라인드 플랜지 등 부품을 생성·복사·교체할 때 대상 위치의 제작 지정을 확인한다. 별도 지정이 없으면 복사 원본의 `SHOP FALSE`도 `SHOP TRUE`로 바꾼다. 현장 용접으로 지정된 부품과 접합부는 해당 지정을 유지한다. 플랜지의 현장 볼팅만으로 목의 용접을 현장 용접으로 분류하지 않는다. 한 부품의 양 끝에서 용접 구분이 다르면 접합부별 지정과 스풀 경계를 따른다. 작업 후 대상 BRAN별로 모델링한 구성품의 `SHOP`을 다시 읽어 `TRUE` 수량과 현장 지정 예외를 확인한다. `SHOP` 속성이 없는 부품은 설정·집계 대상에서 제외한다.

## 요청에 따른 시작점

| 사용자가 원하는 일 | 먼저 할 일 | 마무리 기준 |
|---|---|---|
| “이 프로젝트에서 쓸 수 있는 스펙 알려줘” | 선택 프로젝트에서 조회 가능한 PIPE 스펙을 읽는다. 특정 접속에 쓸 수 있는지 묻는 경우 해당 구경·단부의 품목까지 대조한다. | 스펙 목록과 특정 접속에 대한 적합 여부를 구분해 답한다. |
| “두 노즐을 연결하고 밸브와 플러그 드레인을 달아줘” | 양 끝 접속면과 경유 구간을 실측한다. [접속과 루팅](references/routing.md)을 따른다. | 두 노즐 간 연결, 주관의 실제 저점, 드레인 끝단을 모델에서 다시 읽는다. |
| “발판에서 조작하고 스풀도 빼게 루팅을 바꿔줘” | 작업자가 설 위치와 탈착 순서를 먼저 정한다. [정비 공간과 서포트](references/maintenance.md)를 적용한다. | 조작, 볼트 인출, 스풀 반출, 잔류 배관 지지 결과를 각각 제시한다. |
| “노즐이 간섭되니 옮기고 인폼 만들어줘” | 변경 전 노즐 면을 기록하고, 승인된 이동 범위에서 재접속한다. [변경 인폼과 재검사](references/handoff.md)를 사용한다. | 변경 후 치수와 영향받은 배관을 다시 읽고 장비팀이 판단할 내용을 문서화한다. |
| “헤더를 랙에 태우고 시작부를 정렬해줘” | 유동 방향과 접속면을 확인하고 경로 제약이 큰 라인부터 평면과 랙 단면에 배치한다. | 랙 지지 높이, 보온 후 간격, 분기·마감과 밸브 정비 공간을 확인한다. |
| “ET가 빠졌거나 ISO에 경고가 떠” | [모델과 ISO 검증](references/rack-headers.md#모델과-iso-검증) 절차로 해당 브랜치와 구성품을 조회한다. | 수정 후 모델을 다시 읽고 해당 라인의 ISO와 출력 로그를 확인한다. |
| “검사 게이지 지워줘” | 현재 모델에서 해당 임시 그룹의 소유 위치와 구성품을 확인한다. | 요청한 그룹이 사라지고 인접한 영구 설비가 남았는지 재조회한다. |

## 한 라인을 처음부터 설계할 때

1. **범위를 잡는다.** 프로젝트·MDB·소유 위치, 라인과 양 끝 노즐, 신규·수정 여부를 확인한다. 이미 지정된 대상은 재사용한다. 현재 모델에서 이름과 소유 장비를 대조한다. 실모델 조회·변경은 [이 플러그인의 E3D 작업 절차](../e3dex/SKILL.md)에 따라 수행한다. 도면만 있는 경우에는 도면 기준 제안과 실모델 확인 사항을 적는다.
2. **접속 조건을 결정한다.** 양쪽 노즐 면 좌표·방향, 구경, 플랜지 규격·등급·면 형상, 적용 스펙과 그 근거를 잡는다. 규격 변경이나 노즐 이설이 필요하면 이미 합의한 결정은 유지하고 새로 필요한 선택만 사용자에게 묻는다.
3. **루팅과 정비 공간을 함께 배치한다.** 구배·장비 유입 조건·열변위로 경로가 제한되는 구간부터 배치한다. 평면과 단면에서 지지점, 인접 라인, 조작 위치, 탈착 경로와 하역 위치를 대조해 주관·분기·드레인을 정한다. 사용자가 일부 검토만 요청하면 해당 구간만 다룬다.
4. **모델에서 결과를 검증한다.** 연결성, 정적 간섭, 부품 이동 중 간섭, 작업자 접근을 각각 검사한다. 바뀐 구간의 이전 검사 결과는 갱신한다. 일치하는 접속면이나 의도된 받침 접촉은 상대 부품을 확인해 설명한다.
5. **결과를 돌려준다.** 변경한 라인·노즐·부재, 치수 기준, 검사를 수행한 범위, 남은 간섭과 저장 여부를 짧게 적는다. 인폼을 요청했다면 해당 리비전 문서를 함께 제공한다.

## 도중에 조건이 바뀌면

노즐 이동은 접속면부터, 발판 변경은 통행·조작 위치부터, 서포트 추가는 스풀 인출과 하중 전달 경로부터 다시 본다. 세션이 끊기거나 일부만 생성됐다면 현재 모델에서 이미 반영된 부분을 먼저 찾아 이어간다. 스킬 호출만으로 기존 장비 변경, 프로젝트 저장, 대외 전송 권한이 추가되지는 않는다.

판정 연습에는 [탱크와 필터를 연결하는 가상 예제](references/routing-example.md)를 사용한다. 실제 배관의 규격과 여유 치수는 해당 프로젝트 자료에서 정한다.
