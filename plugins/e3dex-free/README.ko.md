# E3DEX Free 1.0.0 - 무료 · 로그인 없음 (Claude Code · Codex)

로그인과 결제 없이 쓰는 E3DEX입니다. 마켓플레이스에서 설치하면 처음 도구를 쓸 때 이 PC가 관리 서버에 자동으로 연결됩니다. 배관·구조·장비·PLAN 생성은 관리 서버에서 실행되므로 기능 개선은 바로 적용됩니다. 이 PC에는 E3D 연결·매크로 실행 부분만 설치됩니다.

## 처음 한 번

1. Claude Code 또는 Codex의 플러그인 마켓플레이스에서 `e3dex-free`를 설치합니다. 구독용 `e3dex`와 같은 PC에 함께 설치하지 마세요.
2. 처음 쓰는 PC라면 새 채팅에서 초기 설정을 요청합니다.

> E3DEX 초기 설정해줘. Design과 Draw 연결 모듈을 설치하고, 작업할 프로젝트 로그인 후 읽기 전용 실행까지 검증해줘. SAVEWORK는 하지 마.

초기 설정은 E3D를 닫은 상태에서 E3D 폴더에 E3DEX 애드인을 설치합니다. 폴더 권한에 따라 Windows 관리자 승인(UAC) 창이 뜰 수 있습니다. 설치 뒤 E3D를 켜고 작업할 프로젝트에 로그인하면 연결을 검증합니다.

## 알아둘 점

- 관리 서버에 인터넷으로 연결되어 있어야 사용할 수 있습니다. 매 작업마다 서버가 이 PC의 사용 가능 여부를 확인합니다.
- 관리자가 무료 이용을 끝내면 `FREE_ACCESS_ENDED`가 표시됩니다. 그때는 같은 마켓플레이스의 구독용 `e3dex` 플러그인을 설치하고 로그인하세요.
- 생성 기능 업데이트는 자동입니다. E3D 연결 부분이 바뀔 때만 마켓플레이스에서 플러그인을 업데이트합니다.
- PC를 구분하려고 Windows 장치 ID의 해시값만 서버에 보냅니다. 장치 ID 자체는 보내지 않습니다.
- 연결 해제: "E3DEX 연결 해제해줘". 다음에 도구를 쓰면 자동으로 다시 연결됩니다.

## 오류별 조치

| 표시 | 의미 / 조치 |
|---|---|
| `FREE_ACCESS_ENDED` | 무료 이용이 끝났습니다. 구독용 `e3dex` 플러그인을 설치하고 로그인하세요. |
| `ACCESS_REVOKED` | 관리자가 이 PC를 차단했습니다. 관리자에게 문의하세요. |
| `SERVER_UNREACHABLE` | 관리 서버에 연결할 수 없습니다. 인터넷/프록시를 확인하세요. |
| `LOADER_OUTDATED` | 마켓플레이스에서 플러그인을 최신 버전으로 업데이트하세요. |
| `core_failed` | 서버에서 생성에 실패했습니다. 메시지를 관리자에게 알려주세요. |

## 저장 위치

- 연결 정보: `%LOCALAPPDATA%\E3DBridge\loader\free-auth.json` (Windows 계정 암호화)
- 서버가 만든 매크로, 실행 기록, Python 런타임: `%LOCALAPPDATA%\E3DBridge`

최초 실행에 Python 3.13.13 다운로드가 필요하고, E3D 2.1 / Windows x64 전용입니다. PLAN DXF 내보내기도 서버에서 처리하므로 PC에 별도 패키지를 받지 않습니다.
